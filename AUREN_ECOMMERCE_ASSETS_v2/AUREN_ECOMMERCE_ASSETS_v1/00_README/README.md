# AUREN Ecommerce Assets

Final product-photography package for the AUREN fashion ecommerce build.

## Product image rule
- Primary image: on-model / UGC-style fashion image
- Secondary image: clean product-only studio image

## Collection
16 approved products across 4 categories, with 2 core images each = 32 images.

- T-Shirts: T01–T04
- Shirts: S01–S04
- Jeans: J01–J04
- Track Pants: P01–P04

## Asset usage
Use the primary image first on product cards and product pages. Use the product-only image as the second gallery image.
